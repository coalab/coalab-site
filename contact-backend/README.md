# COALAB 교육 문의 접수 페이지

## 구성
- `web/index.html`: 홈페이지 `/contact/` 업로드용 반응형 문의 폼
- `apps-script/Code.gs`: Google Sheets 저장 및 관리자 이메일 알림

## 실제 연결 절차
1. **코아랩에서 관리하는 Google 계정**에 새 Google Sheet를 만들고 `교육문의 관리` 등으로 이름을 정합니다.
2. Sheets URL 중 `/d/` 와 `/edit` 사이의 **스프레드시트 ID**를 복사합니다.
3. [script.google.com](https://script.google.com)에서 새 Apps Script 프로젝트 생성 후 `Code.gs` 내용을 복사합니다.
4. `CONFIG.spreadsheetId` 와 `CONFIG.notificationEmail`을 **실제 값**으로 수정합니다. 업무용 이메일로 알림 받으려면 실제 수신 주소를 입력하세요.
5. Apps Script 편집기에서 `initSheet`를 수동 실행하여 최초 권한을 승인합니다.
6. **배포 > 새 배포 > 웹 앱**: 실행 사용자는 '나', 액세스 권한은 '모든 사용자'로 지정합니다. 외부 사용자에게 공개되는 접수 API이므로 스팸 대비 및 개인정보 관리가 필수입니다.
7. 배포 후 발급되는 **`/exec` URL**을 `web/index.html`의 `SCRIPT_URL` 값에 붙여넣습니다.
8. `web/index.html`을 홈페이지의 `/contact/index.html`로 업로드합니다. 메인 메뉴에서 `/contact/`로 링크합니다.
9. **실제 제출 테스트**: Chrome 개발자 도구 → 네트워크에서 전송 확인; Google Sheet에 1행 추가와 관리자 이메일 알림을 확인합니다. 이메일은 스팸함도 확인합니다.

## 개인정보/보안 운영상 주의
- 고객 데이터는 **사이트 서버가 아닌 코아랩 Google 계정의 Sheets**에 저장됩니다. 작성자를 제외하고 관리자만 시트를 볼 수 있도록 공유를 제한하세요.
- 관리자 이메일에도 문의 내용과 연락처가 들어갑니다. 메일 보안·보존 정책을 함께 관리하세요.
- 안내 문구의 '상담 종료 후 1년'은 **권장 초안**입니다. 실제 기관의 개인정보 처리방침과 보존·파기 정책에 맞게 법률 검토 후 변경해야 합니다. 이 샘플은 **자동 삭제를 구현하지 않았습니다.** 보관기간 만료 시 수동 파기 또는 별도 삭제 배치를 구현하세요.
- `text/plain` 교차 출처 요청은 Apps Script 리다이렉트·브라우저 CORS 정책과 배포 상태에 따라 제한될 수 있습니다. 운영 전 실제 도메인에서 확인이 필요합니다. 제한 시 독립적인 same-origin 백엔드 프록시 또는 Apps Script 웹앱을 직접 폼 엔드포인트로 쓰는 방식으로 조정하세요.
- 공개 엔드포인트는 허니팟만 적용했습니다. 실운영에서는 서버측 속도 제한 및 스팸 방어가 권장됩니다.
- 새 문의를 시트에 기록하는 것과 **상담 완료/견적 발송/계약 완료** 상태 변경은 담당자가 시트의 `처리상태` 열을 직접 수정합니다.
- 이 패키지는 코아랩 Google 계정에 **실제 배포하거나 접수 연결을 완료하지 않았습니다**. 따라서 설정 전 테스트 제출이 저장되지는 않습니다.
