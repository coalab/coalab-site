로봇의 두뇌와 척수 분리 작전:
이종 컴퓨팅 아키텍처

Raspberry Pi 5와 ESP32는 어떻게 완벽한 한 팀이 될까요?

왜 로봇의 뇌를 쪼개야 할까?

우리 몸을 생각해 볼까요? 어려운 수학 문제를 풀 때는 대뇌가 깊게 생각하지만, 뜨거운 난로를 만졌을 때는 뇌까지 신호가 가기도 전에 척수가 반사적으로 손을 떼게 만듭니다.

자율주행 로봇도 마찬가지입니다. 길을 찾고 사물을 인식하는 '인지(대뇌)' 역할과, 바퀴 모터를 밀리초(ms) 단위로 정밀하게 굴리고 장애물 앞에서 즉시 멈추는 '실시간 제어(척수)' 역할을 완벽하게 물리적으로 분리해야 합니다. 이를 이종 컴퓨팅(Heterogeneous Computing) 구조라고 부릅니다.

대뇌 (상위 인지 계층)

Raspberry Pi 5

OS: Linux / ROS 2

  • 주요 임무: 카메라(Vision)와 라이다(LiDAR) 센서 정보를 융합하여 길을 찾고 AI 추론을 합니다.
  • 치명적 약점: 범용 OS(Linux)는 스케줄링이 비결정론적이라 렉(Jitter)이 발생할 수 있어, 0.01초가 중요한 모터 제어에는 부적합합니다.
척수 (하위 제어 계층)

ESP32

OS: FreeRTOS

  • 주요 임무: 정해진 주기(10~50ms)마다 정확하게 모터 속도를 조절(PID 제어)합니다.
  • 강력한 장점: 상위 인지 계층(RPi 5)이 다운되거나 통신이 끊겨도, 결정론적(Deterministic) 타이밍을 바탕으로 즉시 비상 셧다운을 실행합니다.

대뇌와 척수의 통신 (UART)

분리된 두 컴퓨터는 고속 직렬 통신(UART)으로 속도 명령을 주고받습니다. 데이터 파손을 막기 위해 가벼운 '바이너리 프레임 패킷'을 사용하며, 패킷 마지막에는 데이터가 오염되지 않았는지 검사하는 체크섬(CRC)을 반드시 붙입니다.

안전 주의 (교사 시연 필수)

RPi 5는 3.3V를 사용하고, 모터와 ESP32 주변 회로는 5V를 사용하는 경우가 많습니다. 전압이 다른 두 기기의 통신 핀을 직접 연결하면 메인보드가 타버리거나 화재가 발생할 수 있습니다!
따라서 전압을 맞춰주는 레벨 시프터(Level Shifter) 결선은 선생님의 시연으로만 안전하게 관찰합니다.
